## Directory Purposes

**posts/:**
- Purpose: Markdown source files for blog articles
- Contains: 15 `.md` files, each with required `Date: YYYY Mon DD` header on first line
- Key files: `agentfi.md`, `from-late-night-conversations-to-1k-builders-the-story-of-agentic-zero.md` (cover images present)
- Relationship: Each `.md` file → one HTML output in `docs/`

**pages/:**
- Purpose: Static content pages rendered with `page.html` template
- Contains: `about.md` (author/about page)
- Difference from posts: No date header required; uses `page.html` template (no sidebar metadata)
- Output: `docs/about.html`

**templates/:**
- Purpose: Jinja2 HTML templates with inlined CSS and minimal JavaScript
- Contains:
  - `base.html`: Post article layout; includes theme toggle, cover image support, print styles
  - `index.html`: Homepage listing all posts sorted by date; tagline, links section
  - `page.html`: Static page layout (like about.md); no date metadata
  - `404.html`: Error page for missing routes
- Key feature: All CSS inlined in `<style>` blocks (no external stylesheets, ~8KB per post page)
- Theme variables: Light mode `--ink: #1a1a1a`, dark mode `--ink: #e0e0e0`; toggled via `data-theme` attribute
- Golden ratio typography: 1.618 scale ratio, reading width 38rem

**docs/:**
- Purpose: Generated static site served by GitHub Pages
- Contains: HTML files (one per post + index + 404 + static pages), images, `.htaccess`, `CNAME`
- Generated by: `BlogBuilder.build()` writing to `config["output_dir"]`
- Committed: Yes (all `.html` files and images in git)
- Patterns:
  - Post files: `{slug}.html` (e.g., `agentfi.html` from `posts/agentfi.md`)
  - Static pages: `{slug}.html` (e.g., `about.html` from `pages/about.md`)
  - Size targets: Index <10KB, 404 <3KB, posts <25KB

**tests/:**
- Purpose: Quality assurance and build system verification
- Contains:
  - `test_build.py`: Tests BlogBuilder functionality (incremental builds, post parsing, index generation, page rendering)
  - `test_quality.py`: Performance checks (page size limits), accessibility (semantic HTML, alt text), dark/light theme validation
- Run: `python3 tests/test_quality.py && python3 tests/test_build.py`
- Tests verify: No broken links, heading hierarchy, theme toggle functionality, CSS variables correct

**.github/workflows/ci.yml:**
- Purpose: Automated testing on GitHub
- Triggers: Push to main, pull requests
- Pipeline: Install deps → build blog → run tests

**.build_cache.json:**
- Purpose: Maps source file paths to SHA256 hashes for incremental builds
- Format: JSON object `{ "filepath": "16-char-hex-hash", ... }`
- Location: Project root
- Committed: Yes (tracks build state)
- Generated by: `BlogBuilder._save_cache()` after each build

## Key File Locations

**Entry Points:**
- `blogmaker.py`: Main build command; `python3 blogmaker.py` runs the entire pipeline
- `serve.py`: Development server; `python3 serve.py` starts HTTP server at port 8000
- `.github/workflows/ci.yml`: CI/CD pipeline; runs on push to main

**Configuration:**
- `blogmaker.py` lines 19-30: `CONFIG` dict with site settings
- Environment variable overrides: `BLOG_*` prefix (e.g., `BLOG_SITE_TITLE`, `BLOG_SITE_URL`)
- No `.env` file used; configuration is code-based with env var overrides

**Core Logic:**
- `blogmaker.py`: Entire pipeline in single file
  - `BlogBuilder.__init__`: Initialize cache, Jinja2 environment
  - `BlogBuilder.build()`: Main orchestration (lines 179-269)
  - `BlogBuilder._parse_post()`: Extract metadata, markdown → HTML (lines 62-118)
  - `BlogBuilder._parse_page()`: Parse static pages (lines 143-172)
  - `BlogBuilder._extract_cover_image()`: Isolate first image as cover (lines 120-141)
  - `BlogBuilder._needs_rebuild()`: Check hash cache (lines 174-177)
  - `BlogBuilder._file_hash()`: Compute SHA256 (lines 58-60)

**Testing:**
- `tests/test_build.py`: Build system tests (incremental builds, post parsing)
- `tests/test_quality.py`: Performance/accessibility validation (size limits, alt text, theme)

**Templates:**
- `templates/base.html`: Post template (post content + metadata + navigation)
- `templates/index.html`: Home template (post list + intro)
- `templates/page.html`: Static page template (no date, no nav)
- `templates/404.html`: Error page

**Content Source:**
- `posts/*.md`: Individual blog post markdown files (15 files)
- `pages/about.md`: Static about page

## Naming Conventions

**Files:**
- Posts: Lowercase with hyphens (e.g., `crypto-without-privacy-is-half-finished.md`)
- Slugs: Derived from filename stem, lowercased, spaces→hyphens (e.g., `crypto-without-privacy-is-half-finished.html`)
- Templates: Lowercase with hyphens (e.g., `base.html`, `index.html`)
- Tests: `test_*.py` (e.g., `test_build.py`)

**Directories:**
- Lowercase, no hyphens: `posts`, `pages`, `templates`, `docs`, `tests`
- Special: `.github`, `.claude`, `long term article images` (legacy)

**HTML Output:**
- Post files: `{post_slug}.html` → accessible via `https://0xpili.xyz/{slug}` (via `.htaccess`)
- Index: `index.html` → `https://0xpili.xyz/`
- 404: `404.html` → served on missing routes

**CSS Variables (in templates):**
- Light theme: `--ink: #1a1a1a`, `--paper: #ffffff`, `--accent: #ec4899`
- Dark theme: `--ink: #e0e0e0`, `--paper: #111`, `--accent: #f472b6`
- Spacing: `--space-xs` (0.25rem), `--space-s` (0.5rem), `--space` (1rem), `--space-l` (1.5rem), `--space-xl` (2rem), `--space-2xl` (3rem), `--space-3xl` (4rem)
- Typography: `--scale-1` (0.875rem), `--scale0` (1rem), `--scale1` (1.25rem), `--scale2` (1.5rem), `--scale3` (2rem)

## Where to Add New Code

**New Blog Post:**
- Create: `posts/{slug}.md`
- Format:
  ```markdown
  Date: YYYY Mon DD
  # Title (Optional)

  Content in markdown...

  ![Cover image](images/photo.jpg)  ← first image becomes cover
  ```
- Run: `python3 blogmaker.py` (generates `docs/{slug}.html`)

**New Static Page:**
- Create: `pages/{slug}.md`
- Format:
  ```markdown
  # Title

  Content (no date header needed)
  ```
- Renders with: `templates/page.html`
- Output: `docs/{slug}.html`

**New Template Component:**
- Add to: `templates/base.html`, `templates/index.html`, or `templates/page.html` (as appropriate)
- CSS: Add within `<style>` block (all CSS must be inlined, no external stylesheets)
- JavaScript: Add within `<script>` block at end of template (theme toggle is the only JS currently)
- Size limits: Must keep post pages <25KB total (including ~8KB CSS overhead)

**New Tests:**
- Add to: `tests/test_build.py` (for build system) or `tests/test_quality.py` (for HTML validation)
- Pattern in test_build.py: Use `tempfile.TemporaryDirectory()` and `_make_config()` helper
- Pattern in test_quality.py: Load `docs/*.html` files, validate size, structure, theme toggle

**Configuration Changes:**
- Modify: `blogmaker.py` CONFIG dict (lines 19-30)
- Or: Set environment variables before running (e.g., `export BLOG_SITE_TITLE="New Title"`)

**Development Server:**
- For local preview: `python3 serve.py` (runs on port 8000, serves `docs/` with no-cache headers)

## Special Directories

**docs/:**
- Purpose: GitHub Pages root; all generated HTML, images, config live here
- Generated: Yes (entire directory regenerated on each `blogmaker.py` run)
- Committed: Yes (HTML files and images checked into git)
- Contains: Static site ready to serve, no dynamic content

**.build_cache.json:**
- Purpose: Incremental build cache; tracks file hashes to avoid unnecessary regeneration
- Generated: Yes (created/updated by `_save_cache()` after each build)
- Committed: Yes (allows fast incremental builds across machines)
- Format: JSON mapping filepath → 16-char SHA256 hex

**.github/workflows/:**
- Purpose: GitHub Actions CI/CD pipeline definition
- CI Pipeline: Install deps → build blog → run tests
- Committed: Yes (ensures tests run on every PR/push)

**long term article images/:**
- Purpose: Legacy image directory (not currently integrated into build)
- Status: Orphaned; not referenced in any posts or templates
- Action: Can be deleted if not needed
